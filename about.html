About DocuTools

DocuTools is a small collection of PDF and document tools built to be genuinely useful, quick to load, and honest about what they can and cannot do. "DocuTools" is a working name chosen for this initial build; it can be renamed later without changing how any of the tools function.

What we are trying to do

Most people occasionally need to merge a couple of PDFs, pull a page out of a document, shrink a photo, or turn a scanned page into text. DocuTools focuses on that everyday work: fourteen focused tools instead of one bloated application.

How the tools are built

The site itself is plain HTML, CSS and JavaScript with no framework. Individual tools call on a small number of well-known open-source libraries — including pdf-lib, PDF.js and Tesseract.js — to do the underlying PDF, rendering and text-recognition work, loaded from a public content delivery network only when a specific tool needs them.

Our approach to accuracy

We would rather clearly explain a limitation than pretend a tool did something it did not. If a browser cannot genuinely perform an operation — such as fully compressing an arbitrary PDF the way dedicated desktop software can — the tool page says so, and only reports results that were actually measured.

Where this is hosted

DocuTools is built as a static site so it can be hosted for free on services such as Cloudflare Pages or GitHub Pages, without requiring a database or a paid server.
