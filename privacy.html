Privacy Policy

Last updated: this policy applies to the current version of the DocuTools site described in this project.

Local, browser-based processing

Tools on this site that are labeled "processed locally in your browser" read and transform your file using JavaScript running on your own device. The file itself is not uploaded to a server operated by DocuTools as part of that processing.

Third-party libraries loaded from a CDN

Some tools (for example those that use pdf-lib, PDF.js, Tesseract.js or JSZip) load a JavaScript library from a public content delivery network the first time you use that tool. Loading that script involves a request to the CDN provider, which may log standard web request information such as your IP address, in the same way any website asset request does. Your document content is not included in that request.

No document storage

We do not save copies of the files you process, and we do not have a database of user documents. Once you close or navigate away from a tool page, any file data held in your browser's memory is discarded.

Cookies and analytics

This version of the site does not set tracking cookies and does not include any analytics or advertising script. If analytics or advertising are added in a future version, this policy will be updated to describe exactly what is collected and why.

Information you provide directly

If you contact us using the email address on the Contact page, we will see whatever information you choose to include in that message, such as your email address and message content. We use that only to respond to you.

Children's privacy

DocuTools is not directed at children and we do not knowingly collect personal information from children.

Changes to this policy

If this policy changes in a meaningful way, the "last updated" note above will be revised.

Contact

Questions about this policy can be sent using the details on the Contact page.
