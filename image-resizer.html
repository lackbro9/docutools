Supports JPG, PNG and WebP, up to 25 MB.

    Resized image

    How to use this tool

    1. Upload an image.
    2. Enter the width and/or height you want. Aspect ratio is locked by default so the image is not stretched.
    3. Click "Resize Image".
    4. Preview the result and download it.

    Limitations

    Enlarging an image beyond its original size will not add real detail; it will look softer or blurrier. Dimensions are limited to 8000px per side to keep processing reliable in the browser.

    Privacy

    This tool processes your file locally in your browser. Your file is not uploaded to a server as part of this operation.

    Frequently asked questions

    Will resizing change the file format?

    No, the output keeps the same format as your uploaded image (JPG, PNG or WebP).

    Can I unlock the aspect ratio and stretch the image?

    Yes, untick "Lock aspect ratio" to set width and height independently.

    Is my image uploaded anywhere?

    No, resizing happens locally in your browser using the Canvas API.
