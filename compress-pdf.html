    How to use this tool

    1. Upload a PDF file.
    2. Choose "Optimize" for a safe pass that keeps text selectable, or "Strong compression" for larger savings on image-heavy or scanned PDFs.
    3. Click "Compress PDF".
    4. Check the before/after size comparison, then download the result.

    Limitations

    Arbitrary, reliable PDF compression is genuinely hard to do inside a browser. "Optimize" mode re-saves the PDF structure and typically yields modest savings. "Strong compression" mode renders each page to a JPEG image, which can shrink image-heavy or scanned documents significantly, but text is no longer selectable or searchable afterward, and text-heavy PDFs can sometimes get larger, not smaller. DocuTools always measures and reports the real result rather than assuming a reduction. If you need guaranteed, high-ratio compression that preserves text, a dedicated desktop tool or a future server-side option may work better.

    Privacy

    This tool processes your file locally in your browser. Your file is not uploaded to a server as part of this operation.

    Frequently asked questions

    Why did my file get bigger instead of smaller?

    This can happen in either mode: "optimize" has little to gain on an already-efficient PDF, and "strong compression" can produce a larger file for text-heavy documents because rendered page images are sometimes larger than compact vector text. DocuTools reports the real measured result either way.

    Will strong compression make my text unselectable?

    Yes. That mode turns every page into a JPEG image, so any text on the page is no longer selectable, searchable, or accessible to screen readers.

    Is my PDF uploaded to a server?

    No, both modes run locally in your browser using pdf-lib and PDF.js.
