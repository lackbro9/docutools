    How to use this tool

    1. Upload a text-based PDF file.
    2. Click "Extract Text".
    3. Review the text in the box, then download it as a .txt file.

    Limitations

    This tool reads the text layer that is already embedded in the PDF. Scanned documents and photographed pages usually have no embedded text layer at all, so this tool will find nothing to extract from them; use the OCR tool for that kind of file instead.

    Privacy

    This tool processes your file locally in your browser. Your file is not uploaded to a server as part of this operation.

    Frequently asked questions

    Why is the result empty?

    The PDF likely contains only scanned images with no embedded text layer. Try the OCR tool, which recognizes text from an image.

    Does this preserve formatting like tables and columns?

    No, the output is plain text in reading order as reported by the PDF, without layout formatting.

    Is my PDF uploaded to a server?

    No, extraction happens locally in your browser using PDF.js.
