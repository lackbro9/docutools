    How to use this tool

    1. Upload a PDF file.
    2. Check the boxes for the pages you want to keep, or use "Select all" / "Select none".
    3. Click "Extract Pages".
    4. Download the new PDF containing only your chosen pages.

    Limitations

    For PDFs with a very large number of pages, the checkbox list can get long; the Split PDF tool may be quicker if you just need one continuous range.

    Privacy

    This tool processes your file locally in your browser. Your file is not uploaded to a server as part of this operation.

    Frequently asked questions

    How is this different from Split PDF?

    Split PDF uses typed page ranges. Page Extractor lets you tick individual pages visually, which is handy for picking out a scattered set of pages.

    Can I pick pages out of order to rearrange them?

    Extracted pages keep their original order in the output PDF.

    Is my PDF uploaded to a server?

    No, extraction happens locally in your browser using the pdf-lib library.
